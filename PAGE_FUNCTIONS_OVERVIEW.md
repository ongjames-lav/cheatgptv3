# CheatGPT Page Functions Overview

## Analytics Home Page (/analytics/home)
- **Recent Videos Display**: Grid view of recent monitoring sessions with thumbnails and key metrics
- **Dual Tab Interface**: Switch between recorded sessions and processed videos
- **Quick Stats**: View session count, total duration, and event statistics
- A central dashboard for accessing and managing all classroom monitoring content.

### Button Functions
Users can interact with the following controls on this page:
- The Refresh button (🔄) allows users to reload all sessions and update the statistics in real-time.
- Using the Select button (☐), users can enter multi-select mode to perform operations on multiple sessions at once.
- The view can be toggled between Grid and List modes (⊞/≣) to accommodate different browsing preferences.
- Sessions can be sorted (⇅) by various criteria including newest first, oldest first, or by event count.
- Each session can be watched directly by clicking the Watch button (▶) which opens it in the analytics player.
- Reports can be downloaded (📄) in PDF format for any selected session.
- Sessions can be permanently removed using the Delete button (🗑️), which requires password confirmation for security.

## Live Monitoring Page (/)
- **Real-Time Detection**: Live classroom behavior monitoring with instant alerts
- **Camera Controls**: Adjust monitoring settings and recording parameters
- **Event Log**: Real-time tracking of detected behaviors
- The primary interface for active classroom monitoring and behavior detection.

### Button Functions
The live monitoring interface provides several essential controls:
- Camera monitoring can be initiated using the Start Camera button (🎥) which initializes the webcam and begins the detection process.
- Users can stop the camera feed at any time with the Stop Camera button (⏹️) to pause monitoring activities.
- Recording sessions can be started (⏺️) and stopped (⏹️) as needed to capture specific monitoring periods.
- Important moments can be captured using the Screenshot button (📸) which saves the current frame.
- The event log can be cleared using the Clear Events button (🗑️) to start fresh.
- System sensitivity and detection parameters can be adjusted through the Configure button (⚙️).

## Upload Page (/upload)
- **Drag-and-Drop Upload**: Easy file upload interface
- **Batch Processing**: Handle multiple video uploads
- **Progress Tracking**: Monitor upload and processing status
- Interface for uploading and processing pre-recorded classroom videos.

### Button Functions
The upload interface provides several tools for managing video uploads:
- Videos can be selected through the file browser (📁) or by dragging and dropping.
- Uploads can be initiated using the Start Upload button (⬆️) once files are selected.
- Ongoing uploads can be cancelled (✖️) if needed.
- The upload queue can be cleared (🗑️) to remove pending files.
- Selected videos can be processed (⚡) for behavior detection analysis.
- Processing results can be reviewed immediately using the View Results option (👁️).
- Failed uploads can be retried (🔄) without needing to reselect files.
