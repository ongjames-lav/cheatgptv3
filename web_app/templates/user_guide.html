Welcome to CheatGPT

About CheatGPT

CheatGPT is an advanced AI-powered examination monitoring system that uses computer vision and machine learning to detect and prevent academic dishonesty. The system provides real-time monitoring, recorded video analysis, and comprehensive analytics to ensure exam integrity.

Important: Before implementing CheatGPT, ensure you have:
  • Proper authorization from your institution
  • Compliance with privacy regulations
  • Informed consent from monitored individuals
  • Adequate technical infrastructure

Key Features

  • Real-time monitoring with instant alerts
  • Recorded video analysis with AI detection
  • Comprehensive analytics and reporting
  • Customizable alert thresholds
  • Export capabilities for documentation
  • Multi-user monitoring support

System Requirements

  • Hardware Requirements

    • •Processor: Intel Core i7/AMD Ryzen 7 or better (for real-time processing)
    • •RAM: 16GB minimum (32GB recommended for multi-session monitoring)
    • •Storage: 5GB for installation + 50GB+ for session recordings
    • •GPU: NVIDIA GPU with 6GB+ VRAM (for AI processing)
    • •Camera: Full HD webcam (1080p/60fps recommended)
    • •Network: 10Mbps+ upload (stable, low-latency connection)

  • Software Requirements

    • •OS: Windows 10/11 (recommended), macOS 12+, or Ubuntu 22.04+
    • •Browser: Chrome 100+, Firefox 100+, or Edge 100+ (WebRTC support required)
    • •CUDA Toolkit: Version 11.8+ (for GPU acceleration)
    • •Python: Version 3.9+ with required ML libraries
    • •Webcam drivers: Latest version with H.264 support

    Setting Up Live Monitoring

    Configuring Detection Settings

    Fine-tune detection parameters for optimal monitoring:

    • Head Movement Sensitivity: Adjust threshold for head turn detection
    • Phone Detection: Set sensitivity for mobile device detection
    • Person Detection: Configure accuracy for person presence
    • Alert Threshold: Set minimum confidence level for alerts
  • 3

    Monitoring Active Sessions

    Monitor the session effectively using these features:

    • Real-time Alerts: Instant notifications for suspicious activities
    • Event Log: Chronological list of all detected events
